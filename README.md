# 学伴AI —— 高校一站式学习求职智能助手
> 基于卡奥斯 COSMO Code 无代码平台开发，面向大学生的Web AI应用，无需手写代码，使用自然语言指令完成应用构建。

## ✨ 项目功能
1. PDF知识库RAG问答：上传PDF课件，自动切片构建向量库，问答附带文档来源引用。
2. 六大场景快捷卡片：
- 学习计划生成
- 简历润色
- 论文提纲
- 面试准备
- 代码助手
- 翻译助手
3. 多会话管理，支持新建多个对话，保存聊天记录。
4. 差异化配色UI卡片，蓝紫渐变风格界面。
